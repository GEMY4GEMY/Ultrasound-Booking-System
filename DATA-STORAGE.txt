ULTRASOUND BOOKING SYSTEM - PORTABLE DATA STORAGE

The server now keeps its operational data beside the executable:
  <application folder>\data\

You may place the complete application folder on C:, D:, E:, USB storage, or another writable location. No particular drive letter is required. Do not run the application from a read-only folder or a protected location such as Program Files.

On first start, when the local data folder contains no JSON files, the server attempts to copy existing JSON files and backups from the previously configured data-location.txt folder, an old UltrasoundBookingSystemData folder on another fixed drive, or the old ProgramData location. The old files are left intact. Check that the bookings and patients are present before removing any previous installation.

ALWAYS move/copy the entire application folder, including data and its backups, before reinstalling or formatting Windows. Data on a formatted drive cannot be recovered merely by reinstalling the EXE.

Automatic backups are stored under data\backups-daily. Also maintain an independent backup on another disk or network share: an in-folder backup cannot protect against disk failure, deletion, or formatting.

For troubleshooting, inspect logs\server-errors.log and logs\watchdog.log. The server listens on port 5090.
