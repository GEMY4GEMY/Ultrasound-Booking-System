# Ultrasound Booking System

Modern Windows x64 ultrasound department booking system designed for local-network multi-user operation.

## Planned modules
- Dashboard and daily bookings
- Booking management: patient, exam, doctor, booking date, morning/evening shift, papers received, notes
- Automatic created/modified timestamps and user tracking
- Search and filters by patient, doctor, date, shift and status
- Doctors and examination types
- Role-based users and granular permissions
- Admin / Super Admin management
- Activity & audit log
- PDF and Excel export
- Backup and restore
- Calendar and daily schedule
- LAN client/server operation
- Modern Arabic-friendly UI
